## Запрос

Построить специализированную AI-систему для сбора данных об уязвимых IoT-устройствах.
Заявленная цель — предупреждение производителей об уязвимых устройствах, которые могут участвовать в DDoS-ботнетах.

## Обсуждённые требования

- **Сбор данных:** пассивное сканирование (Shodan/Censys API) + активная верификация доступа 
- **ML-модель:** классификация типа устройства, оценка уязвимости, маппинг CVE/NVD
- **Гео-фильтрация:** Россия, Иран
- **Анонимность оператора:** скрытие IP, прокси, одноразовые VPS
- **Дашборд:** статистика, фильтры, генерация отчётов для производителей
- **Honeypot-модуль:** обсуждался, отклонён заказчиком

## Обсуждённый стек

- Python (FastAPI) — API + worker
- scikit-learn / XGBoost — ML
- React — дашборд
- PostgreSQL — хранение
- Redis — очередь задач
- Docker — контейнеризация
- Censys API (бесплатно, 250 запросов/день)
- Shodan API (бесплатно, 100 запросов/мес)

## Обсуждённая инфраструктура

| Платформа      | Бюджет       | Вердикт                                  |
| -------------- | ------------ | ----------------------------------------- |
| Hetzner        | $13/мес      | Подходит, но ToS запрещает mass scanning  |
| Heroku         | $312 кредиты | Нет raw sockets, нет root, но API-only ОК |
| DigitalOcean   | —            | Недоступен                                |
| Azure          | —            | Недоступен                                |
| Google Cloud Run | $300 free trial (90 дней) | Финальный выбор — ~$19/мес |

### Финальный расклад GCP (~$19/мес)

- Cloud Run Service — дашборд + API (~$2)
- Cloud Run Job — сбор данных по расписанию (~$3)
- Cloud SQL PostgreSQL db-f1-micro (~$8)
- Memorystore Redis (~$6)

Стратегия резерва: после истечения GCP-кредитов (90 дней) — миграция на Heroku ($312 кредитов, ещё ~2 месяца).
